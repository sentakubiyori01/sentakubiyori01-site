# フィギュア作品ポートフォリオ

画像モックアップをもとにした、HTML / CSS / JavaScriptのみで動作する静的サイトです。

## 主な機能

- 正方形の作品トップ画像
- 作品カードをクリックすると、ページ遷移せずモーダルで詳細表示
- 完成品・背面・3Dモデル・分割・仮組み・サフ画像の切り替え
- サムネイル、左右ボタン、ページインジケーター
- 工程ごとの完了日を表示する制作ログ
- カテゴリ絞り込み
- ページ送り
- 制作中作品と進捗表示
- 近況欄
- 「つなぐ」への依頼導線
- スマートフォン対応

## 開き方

`index.html` をブラウザで開くだけで確認できます。

ローカルサーバーを使う場合：

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 作品の追加・編集

`script.js` 冒頭の `works` 配列を編集します。

```js
{
  id: 1,
  title: "作品名",
  cover: "assets/トップ画像.jpg",
  categories: ["original", "deformed"],
  categoryLabel: "オリジナル",
  description: "作品説明",
  height: "約120mm",
  material: "光造形レジン",
  year: "2026",
  images: [
    "assets/正面.jpg",
    "assets/背面.jpg",
    "assets/3d-model.jpg"
  ],
  imageLabels: ["正面", "背面", "3Dモデル"],
  timeline: [
    ["2026.07.01", "モデリング完了"],
    ["2026.07.03", "分割完了"],
    ["2026.07.12", "完成"]
  ]
}
```

## 変更が必要な箇所

- `index.html` の作家名・説明文
- X / Instagram / BOOTH / note / メールのURL
- 「つなぐ」のURL
- `assets` 内のサンプル画像
- 依頼内容・価格・納期
- フッター情報

## 無料公開

GitHub Pagesで無料公開できます。

1. GitHubに新しいリポジトリを作成
2. このフォルダの中身をアップロード
3. Settings → Pages
4. Branchを `main`、Folderを `/root` に設定
5. 表示されたURLにアクセス


## 追加ページ

- `news.html`：近況・制作日記ページ
- `guestbook.html`：メッセージ投稿と返信掲載ページ

## メッセージフォームについて

GitHub Pagesは静的サイトなので、フォームだけで投稿内容を保存・公開することはできません。
このサンプルでは無料枠のあるFormspreeを利用する前提です。

1. Formspreeでフォームを作る
2. `guestbook.html` の以下を変更する

```html
action="https://formspree.io/f/あなたのフォームID"
```

3. 届いたメッセージを確認する
4. 掲載したいものを `guestbook.html` の `.guestbook-entry` として追加する

この方式なら、迷惑投稿を自動公開せず、確認してから返信を載せられます。


## 名刺デザイン反映版

## 第四版：データファイルで更新

HTMLを直接編集しなくても、以下のJSONだけで内容を更新できます。

- `data/works.json`：作品一覧と作品詳細
- `data/news.json`：ホームの近況と近況ページ
- `data/guestbook.json`：ホームのメッセージとメッセージページ

`news.json`を更新すると、ホームには新しい順で4件、近況ページには全件が自動表示されます。

`guestbook.json`を更新すると、ホームには新しい順で2件、メッセージページには全件が自動表示されます。

### メッセージ送信

GitHub Pagesには投稿を保存するサーバー機能がないため、送信ボタンはメールアプリを開く方式に変更しました。404にはなりません。

送信先は `site.js` の次の行で変更できます。

```js
const CONTACT_EMAIL = "sentakubiyori01@gmail.com";
```

### 注意

JSONはGitHub Pages上ではそのまま動きます。PCで確認する場合、`index.html`を直接開くとブラウザの制限でJSONを読み込めないことがあります。その場合は以下を実行してください。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。
